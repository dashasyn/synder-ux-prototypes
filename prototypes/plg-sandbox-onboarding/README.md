# PLG Sandbox onboarding

Interactive static prototype for Synder PLG Pro Sandbox post-payment onboarding: a 3-step survey, a success / next-steps card, and the in-app Setup Health Score widget (Spec §4).

Open `index.html` and use the dark top bar to switch **Survey → Success → App**, try Sync mode / Score / Layout (Sidebar vs Main) on the App view, and **Reset** to clear survey state. Click through options (including the activation-session shortcut and “fill later”) to see how success copy and health-score checkpoints change.

Intended for the Synder UX prototypes hub at `/prototypes/plg-sandbox-onboarding/`.
