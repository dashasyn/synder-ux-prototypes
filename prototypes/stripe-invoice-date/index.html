Invoice date New Upgrade to use
Select which date Synder posts Stripe invoices under in your books — Created date, when Stripe created the invoice, or Issued date, when the invoice was issued to the customer.

New Stripe connections default to Issued date. Existing connections stay on Created date until you change them. Already-synced invoices are not re-dated.

info
The Synder transactions table always shows the invoice created date. The accounting entry date follows this setting. Sync info on a transaction shows the issued date when it differs from created.

Schedule start date

Select when recognition schedules start for Stripe invoices. Set by a success specialist during RevRec configuration; changeable afterwards.

Schedule start date
Select the date Synder starts the recognition schedule from — Invoice created date, Invoice issued date, or Payment date. Changing this applies going forward only; existing schedules keep their dates until a success specialist rebuilds them.
Sync lock: When Schedule start is Invoice created date or Invoice issued date, the Sync Invoice date setting cannot be changed (see PT · RevRec lock). When Schedule start is Payment date, Sync Invoice date can be changed.

Schedule details Issued date column

Issued date appears for all RevRec orgs. Pre-release rows stay blank; post-release rows are filled regardless of Schedule start.
