# Synder Per Transaction Dashboard Prototype

Open `index.html` (or `dashboard-switcher.html`) in a browser.

Sticky top bar switches **A / B / C / D** instantly (no reload):
- **A** — Triage first
- **B** — Health + activity
- **C** — Ops command center
- **D** — Progress + actions (score + next actions, no feed)

Deep links: `variant-a.html`, `variant-b.html`, `variant-c.html`, `variant-d.html` (standalone).
Hash deep-link on the switcher: `#a`, `#b`, `#c`, `#d`.
